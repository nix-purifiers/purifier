## Contract

`rubygems0811ConsumerSdk` accepts the original SDK and its actual runtime, compiler, stdenv, bootstrap build and original Ruby/RubyGems archive/library pairs. It emits an immutable wrapper and a separate attestation. Original Ruby1.8.0 has no PATCHLEVEL. The observer runs original ELF32 EM_386 Ruby with pointer width4 and platform i686-linux-gnu, original Gem0.8.11 and only bundled sources0.0.1. It activates `require_gem`; it neither loads Bundler nor provides Kernel.gem/Gem.loaded_specs compatibility aliases.

The versioned private ASCII primitive serializer supports only strings, integer, boolean, null, arrays and string-keyed objects. It emits canonical JSON, escapes all ASCII controls/quote/backslash/DEL and rejects nonASCII bytes and floats. No JSON gem is installed or loaded into the SDK. Attestation JSON is parsed strictly by the host Python/Ruby contracts with duplicate, canonical encoding, shape and size checks; the native encoder never evaluates or deserializes attestation text.

Python remeasurement binds actual executable ELF/hash, original archive hashes and library NARs, bundled sources original source/spec/library and explicit cache absence, executed exact GCC4.8.3 version/target, original runtime/stdenv/compiler/bootstrap ATerm bytes and input/output relations. The implicit compiler is traced from the actual runtime stdenv input, its captured derivation and setup.defaultNativeBuildInputs to the compiler output, rather than inferred from a unioned closure. The host Ruby contract independently checks fields, hashes, canonical identity and physical joins; full ATerm relations are verified by Python remeasurement. Both are mandatory before indexing. Core obtains the executed SDK references independently through Nix exportReferencesGraph; caller-supplied consumerClosure is not authoritative. Every wrapper closure root is physically rehashed, including verifier runtimes and original build environment. Captured derivation text loses context only for provenance serialization; actual index/SDK/encoder/attestation/closure contexts retain normal inputIdentity semantics.

## Indexing and native semantics

The complete advertised manifest contains yaml, yaml.Z and validated gems/full_name.gem files only. Original remote_installer tries compressed YAML then plain YAML; HEAD yaml drives its cache. A failed mixed-case URI may also be retried lowercased by the original SDK, so yaml.z404 is an observed failed request rather than an advertised output. Original Marshal use is local cache IO; no remote Marshal, quick or modern index endpoint is emitted.

The original SDK parses every package and builds SourceIndex.new(Hash), YAML and Zlib output. Before any index write, the encoder validates every filename/coordinate, numeric version, duplicate coordinate, Ruby minimum, pure ruby platform, absence of source extensions, and complete unique confined write manifest, then serializes both outputs. It rejects hidden/nested/symlink/special inputs and unexpected preexisting endpoints. A fresh native observation must byte-match the observation extracted from the fully validated exact attestation. Nix verifies the actual SDK against its authoritative closure before invoking the projector.

The original0811 CLI can print a Ruby-minimum error and exit0. Tests preserve that status, then require the original Installer.install(false, owned_home) exception and absent payload/spec. The original post-install still uses its bundled install(true) call after checking actual sources minimum/platform/dependencies; no consumer force option is added. The packaged bootstrap preloads the exact original cached Gem.sources_spec, uses its genuine public date setter with1970-01-01 and TZ=UTC, and invokes the unchanged original setup entrypoint. It asserts the same cached object survives the original reload and the complete installed spec equals its preinstall original to_ruby bytes. It then removes exactly gems/cache/sources-0.0.1.gem. No SDK source/class/clock patch or archive normalization is performed. Policy/version/date/timezone/cache absence are bound in descriptor, actual build provenance and attestation. A separate original-native source-factory verification process reconstructs the exact expected installed specification; the consumer/probe gains no factory shim.
